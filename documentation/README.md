# Contents

In this folder, we keep the design and documentation files. Please _only_ upload flat text files to this folder, these are `txt` and `md` files for example. Word files do not play nice with git so these are not advised.

* UML: The unified modeling diagrammes for our project.
* user-stories: The user stories for our project, acceptance test included for each user-story.
* acceptance-tests: Contains a template of all acceptance tests for each user-story. However, the real acceptance tests are written within the user story files in the user-stories folder.
